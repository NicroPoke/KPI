DecisionDex Core Module Demo

This page demonstrates the core utility modules.

Available Modules:

  • Generator: Infinite generators and timeout iterators
  • Memoization: LRU, LFU, and TTL caching strategies
  • PriorityQueue: Bi-directional priority queue
  • AsyncUtils: Async array map with abort support
  • StreamProcessor: Stream-based data processing
  • Events: Simple EventEmitter / Reactive system
  • AuthProxy: Request wrapper for API keys and tokens
  • Logger: Logging with decorators
